# 多平台：安卓、鸿蒙、电脑（11-21 主人提出，待定）

主人：「要是我不用苹果手机了怎么办？我用安卓，我还要用鸿蒙，我还要用电脑。」

## 现状
Clio 是 SwiftUI 写的，只能跑在苹果系统上（iPhone、iPad、Apple 芯片的 Mac）。安卓、鸿蒙 NEXT（已不再兼容安卓应用）、Windows 都跑不了，要另写。

## 三条路
1. **先让数据能搬走（不管以后用什么都要做，最先做）**：备份、对话、旅伴、名帖、宠物包用公开、写清楚的格式（JSON + 文件夹），任何平台的客户端都能读。宠物包已经和 DSH Go 兼容。可以加 WebDAV / 自己服务器同步（和「云端」方案同一套）。
2. **苹果电脑几乎白送**：iPad 版在 Apple 芯片的 Mac 上能直接跑，稍调界面就行。
3. **安卓 + 鸿蒙 + Windows**，两种做法：
   - **另写一套跨平台版（Flutter）**：一套代码出安卓、Windows、Linux，鸿蒙 NEXT 有社区维护的 Flutter 移植（DSH Go、Kelivo 就是这样做的）。代价：等于再写一个 Clio，之后两套一起维护。
   - **先做云端，再做薄客户端**：旅伴、记忆、书案、终端都在服务器上跑，各平台只做「聊天界面」，薄的客户端好写得多，也可以先用网页版顶上（电脑、任何手机的浏览器都能用）。

## Claude 的建议顺序
1 → 云端第一步 → 网页版（所有平台先能用）→ Mac 版 → 视使用情况再决定安卓 / 鸿蒙原生（Flutter）。
