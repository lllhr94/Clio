# 设计需求（给 Gemini 等设计外援）

## Clio 是什么

iOS 原生的个人 AI 助手 App。名字来自希腊神话里掌管历史的缪斯 Clio，她的标志物是一卷书。
气质：纸墨、书卷；米白纸色、墨灰文字；安静、克制、精致、耐看。不要赛博、霓虹、拟物过度。

主色（用户可选）：黛（蓝灰）、胭（胭脂红）、竹（青绿）、缃（浅黄褐）、藤（紫）、墨（近黑）。
界面里功能名有「日常 / 书卷」两套叫法，书卷词表见 `AGENTS.md`。

## 1. App 图标

- 意象由主人定，可以用主人选定的宠物角色。原创，不用别家标志。
- 交付三张 **1024×1024 PNG**，**不要自己画圆角**（iOS 会裁）：
  - `light.png`：浅色模式，不透明背景。
  - `dark.png`：深色模式，背景透明或深色，主体提亮。
  - `tinted.png`：单色版，灰度图，iOS 会按用户选的颜色染色。
- 缩到 29×29 也要认得出：主体大、轮廓清楚，不要细线、文字、复杂纹样。像素风的话，先画小图再用最近邻放大到 1024，不要插值。
- 原图放 `design/incoming/app-icon/`；定稿后放进 `App/Sources/Assets.xcassets/AppIcon.appiconset/`，`Contents.json` 写三种外观（`luminosity: dark`、`luminosity: tinted`）。

## 2. 宠物（像素风）

**画什么角色由主人定**，主人会直接告诉画图的一方（Codex 等）。本节只规定技术规范，任何角色都按这个做。

- **原创或有授权**：不照着别家角色、吉祥物描；提示词里不写现有作品或角色的名字，除非主人说明有授权。DSH Go 的鲸娘、Deepy 不在开源范围内，不能进仓库。
- **画布**：正方形，32×32、48×48 或 64×64 选一个，整只宠物所有状态同一尺寸。透明底，整数像素，不要抗锯齿边，轮廓 1 像素。
- **一致**：所有状态里角色大小、位置一致，脚贴在画面底部同一条线上。
- **静态头像**：再给一张闲坐姿态的静态图（就用 idle 第一帧），用作旅伴头像和空状态插画。
- **授权信息**：`pack.json` 的 `author`、`license` 写清楚，App 里会显示。

状态名用下面表里的，或这些别名也认：done（=attention）、awaiting_approval（=notification）、poke_left / poke_right、lifted（=drag）、walking（=roam）。


站在聊天输入框上的小角色，用动作表达助手在干什么。

要的状态（每个都是一段循环或一次性动画）：

| 状态名 | 什么时候 | 循环？ |
|---|---|---|
| idle | 空闲 | 循环 |
| thinking | 思考 | 循环 |
| working | 干活（写东西、打字） | 循环 |
| notification | 等你批准 / 回答（举手示意） | 循环 |
| attention | 做完了（开心） | 一次 |
| error | 出错（懵了） | 一次 |
| sleeping | 睡觉 | 循环 |
| waking | 醒来 | 一次 |
| react-left / react-right | 被戳左边 / 右边 | 一次 |
| tickle | 被连戳（挠痒痒） | 一次 |
| drag | 被拎起来 | 循环 |
| roam | 走路（朝一个方向） | 循环 |
| idle-xxx（可选） | 空闲时偶尔的小动作 | 一次 |

要求：

- 透明背景。所有状态里角色**大小、位置一致**，脚贴在画面底部同一条线上。
- 像素风或手绘都行；像素风请保持整数像素、不要抗锯齿边。
- 交付格式（任选其一）：
  1. **每个状态一个 GIF 或 APNG**，文件名就是状态名（如 `thinking.gif`）。
  2. **每个状态一个文件夹的逐帧 PNG**（`thinking/01.png`、`02.png`…），再附一句每帧多少毫秒。
- 放到：`design/incoming/pet/<宠物名>/`

### 用 AI 出图（Codex、Gemini 等）怎么接

AI 出的「像素风」一般是大图，格子不齐、边缘发虚、颜色很多，不能直接用。流程：

1. 让它出**纯色背景**（白或浅灰）、**单个角色、正面、全身**的大图；每个状态出 2～4 帧，角色大小、站位每帧一致。提示词里写明画布尺寸和「pixel art, flat colors, 1px outline, no anti-aliasing, plain background」，**不要写任何现有作品或角色的名字**。
2. 按 `状态名/01.png、02.png…` 放好，跑：
   `python3 tools/pixelize.py 原图目录 输出目录 --size 48`（尺寸按选定的画布；颜色不想吸到 Clio 调色板就加 `--palette auto --colors 16`）
   它会抠背景、对齐网格、吸到上面的调色板、去毛边、脚贴底，所有状态共用一个外框，并出一张放大 8 倍的 `preview.png`。
3. 看 `preview.png`，个别歪掉的像素手工修（任何能编辑 PNG 的工具都行），再用 `tools/make_pet_pack.py` 打包。

收到后用 `tools/make_pet_pack.py` 做成宠物包（`pack.json` + 序列帧），App 里「宠物设置 › 导入宠物包」就能用，也可以做成内置宠物。

## 2.5 插画（用同一个宠物角色）

App 里有几处大一点的形象位，现在画的是旧形象，要换成宠物角色的**静态图**（从宠物包里取对应状态的第一帧，最近邻放大，不另画）：

| 位置 | 现在的代码 | 用哪个状态 |
|---|---|---|
| 首次打开欢迎页（大） | `SetupView` | idle |
| 正在连接模型 | `SetupView` | working |
| 聊天空状态（大） | `ChatPage` | idle |
| 文件、浏览器等页面空状态 | `StudyPage`、`Browser`、`Drawer` | idle |
| 批准单、填表 | `ApproveView`、`FormSheet` | notification |
| 日课完成 | `Daily` | attention |
| 旅伴头像（列表、编辑、对话里） | `Desk`、`CardEditors`、`ChatPage`、`NoteSheet` | idle |

所以宠物包必须有 idle、working、notification、attention，且第一帧就是好看的定格姿势。

**首次打开引导**（4 页，文案在词典 `onboarding.*`）每页一张插画，像素风、同一个角色、透明底、正方形 96×96：
1. 替你动手（角色在桌前操作文件、终端）
2. 你拍板（角色递上一张批准单）
3. 选称谓（角色拿着两张卡片比较）
4. 接上模型（角色接上一根线 / 打开一扇门）

## 3. 界面小图标（暂不需要）

界面里用的是苹果系统图标（SF Symbols），统一、清晰、自动适配深色和粗细。除非有完整一套风格统一的替代（SVG、单色、线宽一致），否则不换。

## 4. 文案（欢迎润色）

词典在 `App/Sources/Tone/zh-CN.daily.json`（日常）和 `zh-CN.literary.json`（书卷），两份键必须一致。润色时：

- 书卷说法要一眼能懂，不生造词，不用官场、江湖、西式意象。
- 词表里的每个词都是一个功能的名字（书案＝文件，斗室＝终端，港湾＝连接器，更漏＝定时任务，良方＝技能，便笺＝批准单，手札＝日记，拾遗＝记忆，别馆＝远程主机），只在说那个功能时用，不要当装饰词造句。
- 按钮保持日常说法。
- 改完给出改动的键和新旧对照。
