# 全项目彻查（Claude，2026-11-21 起）

主人要求：整个项目从头到尾查一遍。按区域过：安全与隐私 → 数据 → 引擎与并发 → 界面与其余。
每条写：在哪、会怎样、修了没有。级别：P1 会丢数据 / 泄密 / 闪退 / 做错事；P2 用着不对；P3 小毛病。

## 安全与隐私

- **A1 P1 机密可能经网页、连接器、浏览器输入框送进模型**：以前只有终端、读文件、远山命令的输出会隐去信匣里的机密；网页读取、MCP 连接器、远游页面（比如「显示密码」后的输入框）都不经过。**已修**：引擎里加一道统一关卡（`Agent.screen`），所有工具结果和报错都先隐去机密、超过 6 万字截短，主对话和「请别的旅伴帮忙」两处都接上。
- **A3 P1 网页里藏的指令可以绕开「以后都允许」**：读过网页后才强制问的只有终端、填机密、远山、书案外写文件；发邮件、记进常记、加定时任务、填网页表单这些，只要用户点过「以后都允许」或「这段都放行」就直接做。读网页的工具也不全：正文模式、邮件、云盘、剪贴板读进来的字都没算。上一轮读过的网页还在对话里，下一轮却从「干净」开始。**已修**：读过外部内容后，凡是本来要问的一律重新问；记忆、定时、发信、日历、通讯录、开链接、网页填字也加进必问；邮件、云盘、剪贴板、浏览器各读法都算外部内容；对话里还留着外部内容时，新一轮一开始就算读过。
- **A4 P1 读网页不限大小**：模型给一个超大文件的链接，整份下载进内存，可能把 App 撑到被系统杀掉。**已修**：边下边数，超过 15 MB 就停。
- **A5 P2 网页跳转能把请求送到局域网**：读网页时公网地址可以重定向到路由器、NAS 这类本地地址，请求已经发出去才检查；远游里旅伴点链接也能点进局域网地址。**已修**：重定向到本地地址直接不跟；旅伴操作自己的标签时不许进本机和局域网地址（用户手动去不受限）。
- **A6 P2 MCP 服务回的内容不限大小**：一直不停发、或回一大坨的服务会把内存吃光，或者让这一步一直挂着。**已修**：一次回复最多 12 MB。
- **A7 P3 诊断记录可能带出机密**：报错原文进诊断，用户会复制出来发给别人。**已修**：写进诊断前也隐去信匣里的机密。
- **A8 P2 书案里的链接可以指到书案外面**：斗室里 `ln -s` 做一个指向 App 自己数据的链接，读写文件工具会顺着链接走出去（读密钥的备用文件、改对话记录）。**已修**：书案的文件工具按链接真正指向的位置判断，出了书案就拒绝。
- **A9 P1 模型可以把要密码的笺写成「不保密」**：递笺时字段是否保密由模型说了算，网页里藏的指令可以让它要「登录密码」却不标保密，用户填的密码就会明文回到模型那里。**已修**：字段名里有密码、验证码、卡号、令牌、密钥这类字样的，一律按保密处理，存进信匣、只给模型编号。
- **A10 P3 网盘返回的文件名没检查**：带 `../` 的名字下载时可能写到临时文件夹外面。**已修**：只接受普通文件名。
- **A2 P2 回答写到长度上限、正好断在工具调用中间时，半截参数可能照样执行**：只处理了「连接断了」的情况。**已修**：长度截断时同样不执行，并提示「写到长度上限」。

## 数据

- **D1 P1 远山和斗室读不了稍大的文件**：读文件走命令行、内容按 base64 回来，远山输出只留 20 万字，大约 150 KB 以上的文件就读坏或读失败；撤回快照、改文件、看图都受影响。斗室还会把几万行 base64 逐行刷进终端，主线程跟着卡。**已修**：文件操作走单独的安静通道（`execQuiet`），远山留足 6 MB，斗室不往终端里打。
- **D2 P1 撤回把「主机连不上」当成「文件不存在」**：判断「不存在」时匹配了 “not found” 这类宽泛字样，「host not found」会被当成新文件，撤回时把真文件删掉；反过来斗室和远山真正的「没有这个文件」（`WorkspaceError.missing`）却没认出来。**已修**：只认确切的「没有这个文件」。
- **D5 P1 「另起一叶」「翻回旧的」在手机存不下时会丢整段对话**：先把当前对话另存一份（失败也不管），再把页面清空；另存没成功时这段就没了。翻回旧的、撤销压缩时，旧文件在新内容真正写进手机之前就删了。**已修**：另存确认成功才清空，失败就原样不动并提示；翻回和撤销压缩先等新内容落盘，再删旧文件。
- **D7 P1 对话文件只要有一处读不出来，整段就被当成空的，下一条消息会把原文件覆盖掉**：比如升级后格式变了、文件写坏了。**已修**：读不出来时先把原文件另存一份（`….broken-时间.json`），能读的消息一条条救出来，并记进诊断。
- **D8 P2 首页「找过去聊过的话」每敲一个字、每次界面刷新都在主线程把所有对话和收起的旧絮语从磁盘读一遍**，还把所有对话永久留在内存里。**已修**：停手 0.25 秒后在后台查，没打开的对话只为这次查找读，不常驻内存。
- **D9 P2 备份整份拼在内存里**：照片多时可能把 App 撑爆；读不出的文件被悄悄跳过。**已修**：边读边写进文件；有读不出的文件就明说、不出半份备份；撤回用的文件副本和文档缓存不进备份。恢复时先停止存盘再等排队的写完，避免写到一半时被替换。
- **D10 P2 删掉旅伴或雅集后，它的定时任务照样到点弹通知、托付的「到点发消息」照样留着；收起的旧絮语、前情提要、对话设置、撤回副本都留在手机里（也进备份）**。**已修**：删的时候一并取消、一并删掉。
- **D6 P3 设置、旅伴、常记等存盘失败没有任何记录**。**已修**：失败写进诊断。
- **D3 P2 改文件前存旧版本失败（比如空间满了）时，这一步不留记录**：撤回时悄悄跳过。**已修**：记成「没能留下旧版本」，撤回时明说没动。
- **D4 P2 同一个文件在两轮里都改过，较新那轮还原失败、较早那轮还原成功**：之后再试一次会把文件写成错的中间状态。**已修**：较新的没还原成，较早的同一文件也先不动。

## 引擎与并发

- **E1 P2 换备用模型时不看这页是否已清空**：模型出错后自动换备用模型接着答，即使用户刚清空或另起一叶，也会把「换备用模型」写进新的一页再接着跑。**已修**：先核对轮次，页面换了就不再接着。
- **E2 P2 远游「请你接手」的卡片出现在所有对话里**：一段对话请你登录，别的对话页也弹这张卡。**已修**：只在提出的那段对话里出现。
- **E3 P3 定时任务把最后一个星期几也取消时，会变成「每天」**。**已修**：最后一天不能取消。

## 界面与其余

- 聊天页发送、插话、排队、中断并发送：看过，带图插话会改为排队发送，没问题。
- 批准单：读过网页后「以后都允许」按钮会藏起来，换成说明；定时任务这类总要问的，说明原来写成「读过网页」，**已改**成按原因显示。

## 已知、这次没改（记下，以后排）

- P3 正在干活时排队的话只在内存里：App 被系统杀掉，排队的那几条会丢。
- P3 浏览器截图、工具带回的图片一直留在 `media/`，不会自动清理，长期会占空间。
- P3 斗室里的链接在「全文搜索书案」时还会被顺着读（内容会经过机密过滤再给模型）。
- P3 宠物包 zip 里每个文件声明的大小可以造假，解压时没有按实际字节再卡一次。
- P3 对话绑定的远山主机删掉后，工具回落到书案（提示词里会告诉模型）；更稳的做法是直接拒绝，等主人定。

## 检查方式

- 逐个读了：备份与恢复、存盘、撤回快照、归档（另起一叶 / 翻回 / 压缩）、引擎主循环与两家模型服务的流解析、工具关卡（应许 / 读网页后加封 / 批准单）、信匣与机密过滤、浏览器、网页读取、MCP、远山 SSH 与隧道、书案路径、定时与托付、删旅伴、全局搜索、网盘。
- 全局扫了：强制解包、越界下标、外部数字转整数、直接写数据目录的地方。
- 每批改完都跑了 CI 编译和引擎测试。
