# Open Minis 的手感规则，Clio 该学哪些（2026-11-21）

来源：Open Minis 公开仓库 `src/ios/MinisTests/Standalone/`，322 个测试文件，开头注释写了 233 条规则（`[T-…]` 标签）。每条都写了用户怎么反馈、为什么这样定。这里只读注释、学思路，GPL 代码不抄。

第一遍只挑了界面相关的 39 条；主人指出其余的也可能有用（只是还没撞上），第二遍把全部 316 个文件都过了，又挑出 26 条稳定性、后台、模型对接相关的（第六、七节）。剩下的是 Minis 独有的东西（手机里跑 Linux 的 JIT、iSH 内核、Copilot / Codex 登录、iCloud 同步、Android 互通、语音纠错），Clio 没有这些功能，学不了。主人在「要不要」一列勾选，没勾的不做。

状态：✅ Clio 已有或已改 · 🔨 这次 Claude 顺手改了 · ⬜ 没有
