Clio 0.35

【聊天更稳、更顺手】
· 聊天界面更清爽：顶栏收矮，正文、代码块、表格和引用排版重新打磨；代码里的中文按等宽全角对齐，不再拉宽字距
· 顶栏下方直接显示当前模型与支持的思考档位，随时切换且不会压住滚上来的正文；计划清单从输入框上沿顺滑展开
· 连续跑多条终端或远程命令自动折叠成一张卡，点开可逐条看完整命令和已保存的输出，超长时标明截断，并标出「失败」或「结果未知」；单轮步数上限默认放到 40 步（可在设置里选 16–100 步），到上限后可一键「接着做」
· 加强了长对话流式回复、翻看旧消息滚动位置和审批切换时的视图稳定，同时修了宠物浮窗偶尔拦触摸的问题
· 缓存已定稿的正文、表格和图片缩略图，减少长对话滚动时的重复排版；改进小地图、上一句和下一句的跳转落位
· 养护页的掉帧记录会自动刷新。复制诊断时可看到近期界面操作轨迹和掉帧分档，操作轨迹不含聊天正文
· 侧边栏统一管当前和旧对话：左滑可归档／恢复和删除，长按菜单可置顶、改名、打颜色标签、归档和删除；排队待发的消息跨重启保留，撤回时图片一起回到输入框
· 选字后可直接朗读或引用追问；回复可一键存成 Markdown 笔记，系统共享来的内容也能直接带进草稿

【审批更省心】
· 权限页新增「智能审批」：查网页、读文件、看手机状态直接做，写入、发信、跑命令等仍先问你；原有「不许」不会被改写
· 聊天底部批准卡支持「本对话放行」，长说明可滚动看全；带完整命令或脚本的终端、SSH 和脚本强制单可就地确认「准这一次」，发邮件、填密码、加定时等仍走完整确认页
· 改权限时，仍在等待的普通批准单会按当前设置重新判断。单次批准只用于当前操作
· 读过外部内容后，默认继续确认终端、SSH、挂载目录写入等操作。权限页另提供默认关闭的「读过外部内容后仍按权限放行」选项。发 Gmail、从密码箱填入凭据、新建定时任务始终需要确认
· 编辑或删除远程主机时，取消绑定旧配置的待批工作区操作。找不到所选主机时提示重新选择工作地点

【文件、预览与扩展能力】
· 书案支持挂载外部文件夹（如 iCloud Drive、Obsidian 目录），只保存安全书签、不改动原文件；取消挂载或换绑目录后，旧聊天里的图片和预览会立刻失效
· 回答里的 HTML、SVG 支持离线互动预览卡，点开可在独立页面操作、缩放、横屏查看和分享
· 技能支持一键安装（粘贴 GitHub 目录链接或导入 zip，先预览内容再确认安装）
· 联网搜索默认内置网页，可在设置里选外部搜索服务；语音听写新增可选云端转写（密钥按服务存在钥匙串，不进备份）

【模型、工具与养护】
· 模型设置重整：统一「默认模型」页（含默认、备用、记忆整理与生图模型），服务商页和模型详情更清楚；Anthropic 接口开启提示词缓存
· 对话用量页新增「发给模型的内容」，可只读查看每一轮实际发出的系统提示、记忆、技能和工具说明
· 养护页新增「存储与缓存」分项与保守清理；网盘恢复支持选择具体备份；小组件、灵动岛、快捷指令与通知适配深色/纯黑和两套称谓
· 底层引擎、网络、连接器与斗室安全加固（含 SSH、MCP 鉴权、后台续跑与取消），并补齐聊天规则与引擎回归测试
