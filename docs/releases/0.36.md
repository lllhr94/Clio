Clio 0.36

【聊天更顺滑，120Hz 原生阅读】
· 聊天列表升级为原生 UIKit 滚动引擎与后台异步预排版：长对话冷开、120Hz 快速上下滑、载入更早历史消息与小地图跳转都更稳更跟手
· 回复正文采用全新逐帧流式渐显：贴底跟走、上翻或选字时不抢阅读位置，短消息气泡圆角更均匀；长按气泡「⋯」菜单支持「选择文本」随时框选复制
· 顶栏精简为「圆形头像 + 名字」居中胶囊，点开直接弹出原位小卡：支持按供应商切换模型、调整思考深度、查看上下文占比、一键压缩前文及查看资料卡／详情
· 底部输入区收窄抬高并换成柔和奶油磨砂，回底按钮收拢为右下角单颗带未读数字的 `⌄`；对话里双方头像统一为纯身份标识，轻点带微弹反馈
· 设置 › 外观与交互 › 显示与手感支持开关「滚动时沉浸阅读」，打开后上滑自动收起顶栏，轻点正文空白处即可恢复

【纸墨排版、外观与触感升级】
· 全量纸墨配色与对比度升级：新增四套阅读排版预设，提供字号、行距、段距与阅读宽度细调，同时消除了中英混排和用户气泡里的双倍行距偏差
· 触感反馈升级为三档可选（支持低电量自动停震），新增「减弱视觉效果」开关并完善深色、纯黑与高对比度／减透明／减动效／大字号重排无障碍适配
· 重新校准界面缩放（紧凑 / 偏小 / 标准 / 偏大），聊天顶底主控件尺寸与正文缩放解耦，既保留舒展阅读又不挤小按钮点击区
· 支持在模型服务里给模型起自定义别名，同名模型自动消歧显示；聊天图片与 HTML / SVG 互动预览卡片支持一镜到底缩放过渡

【侧边栏、全域搜索与精简设置】
· 侧边栏重整「首页 / 助手与群聊 / 记忆 / 文件 + 终端 / 浏览器 / 远程主机 / 定时任务」工作台入口，并修好侧滑拉开时遮罩同步过渡
· 新增全域搜索：一处搜遍对话、记忆与书案文件，支持中文输入法连续选词防打断，PDF 命中支持点开直跳对应页码
· 设置页大幅瘦身：从原本 9 组收拢为 5 大分组，顶部整合「主旅伴 | 我」双区头卡与两行状态快览，底部改用居中朱印页脚；默认与专用模型、旅伴与群聊、日程与早报、字体与字号间距逐一合并，不再跳转混乱
· 养护页「存储与清理」顶部新增五色多段比例空间条，支持跨目录硬链接去重与「其他」占用统计

【四层记忆与本地文档检索】
· 记忆升级为可对账本地库，支持常驻 / 近期 / 较早 / 封存四层管理、待审提案合并、夜间整理与一键脱敏批量导入；封存撤销可完整还原原本所在层级与置顶状态
· 较早记忆支持按当前问题低成本本地召回，单个对话里关掉记忆后同轮立即生效；书案超大 TXT / Markdown 改用懒排版流畅阅读，挂载文档支持本地全文检索与 PDF 页码定位

【私网安全、远程主机、加密备份与稳健性】
· 新增五域私网识别与「Fake-IP 代理兼容」开关，解决开着代理时联网搜索、读网页和浏览器工具被误拦的问题；局域网与 Tailscale 地址按作用域授权，本机回环与云元数据零豁免拦截
· 联网搜索支持手动选用自定义 SearXNG；只读工具支持并发批处理并加装连续重复轮询刹车；远程主机支持 SSH 多跳跳板与路径绑定主机指纹校验
· 支持口令端到端加密备份与 WebDAV 分块流式上传下载，明文密钥全程不落盘；引擎（AgentKit）412 项自动化测试全部通过
