# Open Minis 的回复排版数值，和 Clio 对照（11-21）

从 Open Minis 公开源码里读出的设计数值（只取数，不抄代码）。基准字号 16.5（Clio 默认 17）。

| 项目 | Minis | Clio 之前 | Clio 现在（11-21 改） |
|---|---|---|---|
| 正文字体 | 系统字（苹方） | 用户选（默认书卷，主人用文楷） | 不变 |
| 行间额外空 | 字号 × 0.25（约 4 点），加字体自带行高 → 约 1.45～1.6 倍 | 固定加几点，被字体自带空隙吃掉 | 行高 = 字号 × 倍数（紧凑 1.35 / 适中 1.5 / 舒展 1.65 / 宽松 1.8），任何字体一样 |
| 段与段 | 12 点（约 0.73 倍字号） | 0.8 倍 | 0.72 倍 |
| 列表项之间 | 0.25 倍字号 | 0.35 倍 | 0.25 倍 |
| 列表缩进 | 每级 24 点，圆点 1.25 倍字号加粗 | 按字号算 | 不变（C27 照 Claude App 调） |
| 标题大小 | H1 1.5× · H2 1.3× · H3 1.15× | +6 / +3 / +1 点 | 不变（主人选了 Claude App：加粗不放大） |
| 标题上下 | 上下各 1 倍字号 | 上 0.9 / 0.7 / 0.35，下 0.5 | 不变 |
| 代码块圆角 | 8 | 14（Clio 规矩：卡片里的小块） | 不变 |
| 代码块标签行 | 有语言名时内容从 28 点处开始，标签和代码之间没有分隔线 | 34 点 + 一条分隔线 | 28 点，去掉分隔线 |
| 代码块内边距 | 下 12 | 上下 12～16 | 上 4、下 12 |
| 代码行距 | 4 点 | 0.3 倍 → 0.12 倍 | 4 点 |
| 代码字号 | 0.845 倍正文（Menlo） | 正文 − 3 | 不变（约 0.82 倍，Maple Mono） |
| 代码块颜色 | 浅色模式纯黑底绿字；深色 15% 灰底绿字 | 暖色底，代码黑字、输出绿字 | 不变（C27 待主人选） |
| 代码块最高 | 400 点后在块内上下滚 | 超过 20 行折起，点开全部 | 不变 |
| 行内代码 | 0.845 倍、圆角 5、橙字、前后各一个极细空格 | 红字、方角底色 | C27：照 Claude App 改成圆角胶囊、主色字 |
| 表格格子内边距 | 左右 8、上下 8，外框圆角 8，线 25% 墨色 | 上下 0.65 倍字号，横线 | 不变（列宽已按 Minis 规则改） |
| 表格、图片上下 | 0.6 倍字号 | 段距 | 不变 |
