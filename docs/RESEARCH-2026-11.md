# 同类 App 新一轮对照（2026-11-21）

主人让把 Open Minis、HanaAgent（OpenHanako）、DSH Go、Cindy、Kelivo 从头到尾再看一遍。下面是看到的新东西，以及 Clio 值得学的部分，按「对主人日常用处 ÷ 工作量」排序。

**许可提醒**：
- Cindy、HanaAgent 是 Apache-2.0，可以改编，但要在 README 致谢里写明；HanaAgent 1.x 的源码没公开，只能看更新说明。
- Kelivo、DSH Go 是 AGPL，Open Minis 是 GPL：只学思路。

## Clio 值得学的（按优先级）

### 第一档：小改动，天天用得到

1. **选区工具条加「引用追问」「朗读」**（DSH Go）。Clio 刚做了正文自由选字，选中后现在只有系统的拷贝；把引用、朗读接上去。朗读时跳过密钥（DSH Go 的做法）。
2. **自己的消息也能长按选字、引用**（DSH Go）。
3. **草稿跨重启保留，附件一起**（HanaAgent）。切走、被系统杀掉，回来输入框里还在。
4. **坏图不连累整段对话**（HanaAgent）。一张读不了的图变成一行占位字，不再让之后每次发送都失败。
5. **「我的气泡颜色」**（Cindy）。几个柔和预设加跟随主题，只染你自己的气泡，自动保证字看得清。
6. **首页「等你回答」提醒**（Minis）。有旅伴在等批准或等你回答时，侧边栏对应对话上有明显标记。

### 第二档：中等，体验提升明显

7. **长对话迷你地图**（Kelivo）。右边一条细条，按你说的话分段，点了就跳；搜索时显示命中数。和刚做的「在对话里找」「回到我上一句」配套。
8. **浮动预览**（Minis）。回复里的网页、图片、文档点开先浮在聊天上，看完一划就回来，不整页跳走。
9. **上下文日志**（Kelivo）。在诊断里能看到上一轮实际发给模型的全部内容（系统提示、摘要、记忆、工具），排查「它怎么不记得」很有用。
10. **图片可以单独移出上下文**（Kelivo）。旧图一直占着上下文、拖慢回复时，长按图片「不再给模型看」。
11. **压缩前预览**（Kelivo）。手动整理时先列出要整理掉哪些、留哪些，可以勾。
12. **分享进 Clio**（Cindy / Kelivo）。从别的 App 分享文字、链接、图片、文件进来，先选发给哪位旅伴，放进输入框，不自动发。（Clio 已有分享扩展，要核对是否这样。）
13. **空闲后整理记忆**（HanaAgent）。聊完停 10 分钟，后台把这段要记的写进常记，不占用聊天时的时间。
14. **余额自动刷新**（Kelivo）。模型服务页的余额定时更新，快用完时提醒。

### 第三档：大功能，单独评估

15. **语音通话 / 语音消息**（DSH Go、HanaAgent）。按住说话、旅伴用语音回、通话中能打断。
16. **只读网盘**（Minis）。挂 WebDAV / SMB / S3 进书案，让旅伴读 NAS 里的文件（主人有 NAS）。
17. **WebDAV / S3 备份和自动快照**（Kelivo）。
18. **让 AI 做一只宠物**（DSH Go）。主人已经提过。
19. **和电脑连成一个**（Cindy）。手机上接着电脑的会话，借电脑上的模型。和 Clio「手机本地」的定位不同，先不做。

## 不学的

- Kelivo 的「世界书」、DSH Go 的「酒馆」：角色扮演方向，和 Clio 的定位不同。
- Cindy 的账号体系和云端同步：Clio 不建账号，数据只在手机上。
- 各家默认开的「主动问候」：容易打扰，Clio 已有晨信，够了。

## 第二轮：界面和交互细节（11-21）

看了源码或说明的具体做法，只列 Clio 还没有、又合得上纸墨风格的。

### 旅伴「像个人」的细节

- **做事时头像会呼吸**（Cindy `CompanionPresenceRing`）：旅伴在做事时，头像外面一圈颜色忽明忽暗（透明度 0.3↔1），做完 150ms 淡出；系统开了减弱动态效果就静止。
- **「记下了」小字**（Cindy `CompanionLearningFooter`）：一轮回复里旅伴记住了你的事、学会了新技能，回复底下多一行灰字「记下了：你不吃香菜」，点了去常记页。
- **记错了能撤销**（Minis `MemoryWriteRevoker`）：在那条「记下了」上长按就能撤掉，不用去常记页找。
- **新消息轻轻浮上来**（Cindy `CompanionEntering`）：只有刚发的消息从下面 8pt、0.96 倍大小浮上来；翻历史、重新进入都不动。
- **一眼看旅伴**（Cindy `CompanionGlanceSheet`）：点旅伴头像弹出一个小卡片：它正在做什么、最近做出来的文件、它的定时任务。

### 聊天

- **发送方式**（DSH Go）：长按发送键选「插话（不打断，下一步看到）/ 打断先做这条 / 排队」。Clio 现在只有排队和插话两种隐含行为。
- **问答目录**（Kelivo `mini_map_sheet`）：一张面板按「你问的 + 它答的开头」列出整段对话，可以搜，点了跳过去。比右边细条在手机上更好点。
- **整轮做成图**（Minis `ChatTurnScreenshot`、DSH Go 长图）：把一问一答排成一张长图分享，或多选几条一起分享。
- **把输入框里的东西挪到另一段对话**（Minis `MoveToSessionSheet`）：写了一半发现发错旅伴了，整段（含附件）挪过去。
- **提问卡片**（Minis `UserAskCardView`）：旅伴问你选择题时，卡片上有进度和倒计时，回答后收成一行摘要；写一半的答案不丢。
- **回答里的小卡片**（Hana、Kelivo、Cindy）：天气、待办、计时、图表在回答里画成原生小卡片，不是一堆文字。Clio 的苹果自带能力（日历、提醒、天气、健康）最适合先做。

### 首页和列表

- **筛选**（DSH Go）：全部 / 正在做 / 等我确认 / 未读。
- **归档有 4 秒撤销**（DSH Go）：归档后提示条上能撤销，切出 App 才真的归档。
- **第一次用的清单**（Minis）：没接模型时首页是三步清单（接一家服务 → 选模型 → 或者从备份恢复），新对话按钮先藏起来，免得点了用不了。
- **对话颜色标签**（Hana 1.5.98）：给对话打颜色标签，侧边栏能看出来。

### 屏幕常亮

- **常亮模式**（Minis `AlwaysOnOverlay`）：旅伴做长任务时可以开一块全黑的屏，只显示当前这一步和用时，每 15 秒挪一下位置防烧屏，点一下就回来。适合放着让它跑。
