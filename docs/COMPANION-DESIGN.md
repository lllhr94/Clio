# 旅伴的性格与标志（0.35 主线，主人已定）

参考 HanaAgent 的「元」、角色卡和 1.x 的「像个人」改进（Apache-2.0，改编处在 README 致谢）。下面每一条都是主人在 11-21 的问答里选定的。

## 1. 性格（书卷：性情）

新建旅伴先选一种性格，选了还能自己改设定。老旅伴升级后一律算「温」。

| 性格 | 一句话 | 说话 | 开口前的心绪写法（标签） | 符号 | 名帖卡背 |
|---|---|---|---|---|---|
| 温 | 先感受，再分析 | 柔和有判断，像懂你的老朋友 | 感受一条 · 联想三条 · 疑问三条 · 想做两条（心绪） | ✿ | 云纹 |
| 明 | 先拆前提，再推理 | 克制、精准、不哄人，有把握就给判断 | 前提三条 · 推理三条 · 薄弱处三条 · 该做两条（沉思） | ◈ | 回纹 |
| 活 | 轻快，爱联想 | 句子短，有趣，敢开脑洞但不跑题 | 第一反应一条 · 脑洞三条 · 想给你的小惊喜一条（念头） | ✦ | 竹影 |
| 白纸 | 什么都不带 | 全按你写的设定 | 不写 | ○ | 素笺 |

- 性格存在 `BotInfo.temper`（`warm / clear / lively / blank`），老数据为空时按 `warm`。
- 三种心绪写法都由 `Pulse` 生成，格式各自固定，回复上方折叠成一行（标签用上表括号里的名字），点开看全文。
- 做过工具的一轮，收尾时可以加一行「回望」：只有这一轮真的改变了想法才写，没有就不写。
- 提示词是 Clio 自己写的，只借「四个池子、影响回答但不机械」的思路。

## 2. 标志

- **专属符号**：随性格，出现在名帖、心绪标签、侧边栏行尾。
- **名帖卡背**：随性格的纸墨纹样（云纹 / 回纹 / 竹影 / 素笺），用旅伴自己的颜色画，代码绘制，不放图片素材。
- **专属朱印字**：默认取名字第一个字（小克「克」、团子「团」），编辑名帖时可以换一个字。现在的朱印字体只裁了「克」一个字，要改成常用字全集（马善政毛笔楷书，SIL OFL，裁成 GB2312 常用字后改名，同 Clio Seal 的做法）；字体里没有的字退回文楷。
- **说话风格**（和性格分开，可叠加）：默认、书信（完整句子，有称呼和落款感）、简短（三句以内）、闲聊（口语，带语气词）。编辑名帖时能预览一个气泡。

## 3. 记忆：夜里整理

- 每天夜里（系统允许的后台时间里），把当天每段絮语里值得记的事整理进常记（去重、合并），并写一篇手札。
- 聊完空闲 10 分钟也整理一次这一段，不占用聊天时的时间。
- 整理过程可以在「常记」页看到：哪天整理了哪些，记了什么、合并了什么。
- 已有的「常记 + 旧事」两层不变。

## 4. 闲谈（书卷：闲话）

- 每位旅伴除了正经的絮语，还有一段「闲谈」：轻快、不调工具、不占工作的上下文，可以用更便宜的模型。
- 闲谈里说到要干活，旅伴先问一句「要我去絮语里做吗？」，你点头后它把事带到絮语里去做，做完回来说一声。
- **主动程度：只提醒约好的事。** 你让它记着的事到点了才来一句，不闲聊打扰。

## 5. 名帖

- 名帖正面的三格改为：性格（符号 + 名字）· 记得 · 模型；落款盖它自己的朱印字。
- 背面是性格对应的纹样。
- **递名帖不带记忆**：只带性格、设定、说话风格、颜色、头像（宠物或照片）。
