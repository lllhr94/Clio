# Clio Design System 2.0：三套差异化原创设计语言提案（Deliverable #8）

> **中立立场声明**
> - 本提案提出三套哲学独立、结构完整、且均能 100% 通过原生 SwiftUI / UIKit（iOS 26）落地的设计语言，另附**融合路径可行性评估（第 五 节）**。
> - **不预设**现有书卷风格必须保留，也**不未经确认就推翻它**。三套方案展示**完全相同的真实复杂工作场景**，避免拿不同内容美化差异。
> - 以下全部数据均遵循 **WCAG 2.1 AA（≥ 4.5:1 文本 / ≥ 3.0:1 非文本控件）** 实测检验。

## 二、三套完整设计语言横向解剖

| 维度 | 方向 A：**素笺 2.0** *(Editorial Ink)* | 方向 B：**清器** *(Native Precision)* | 方向 C：**栖息** *(Quiet Companion)* |
|---|---|---|---|
| **核心气质与隐喻** | 现代精密出版物：温暖、安静、有克制纸墨秩序 | 现代高能生产力仪器：冷静、客观、毫厘对齐 | 低焦虑情感陪伴场：温润有节律、把专业工具柔化包裹 |
| **核心借鉴谱系** | Craft + Claude + 潮汐 + Bear + 微信读书 + iMuseum | Linear + Raycast + Things 3 + Darkroom + 飞书 UD | 潮汐 + Gentler Streak + Finch + CapWords + 有知有行 |
| **底面与材质** | 暖米纸 `#F8F5EE`（可选纯白）/ 深墨 `#191815`（可选纯黑）；仅悬浮 Chrome 用 Liquid Glass | 冷静浅灰 `#F3F4F6` + 纯白面板 `#FFFFFF` + 0.5pt 精密边框；深色冷石墨 `#101216` | 燕麦雾白 `#F5F3EE` + 棉纸卡片 `#FCFAF6`；顶/底静态 Chrome 带柔和 `Ambient State Glow`（可降级细线） |
| **排版纪律** | **UI 轨**全走系统 SF Pro+苹方；**阅读轨**支持书卷/苹方/文楷；仅 `Clio 字标/题词/审批来源` 用 `Ink.mark` | 全界面**系统现代无衬线** + 全量 `.monospacedDigit()`（步骤/耗时/Token）；禁用书法与衬线装饰 | 大标题/晨信可用温和微圆润（`.rounded`），长文正文与代码块严守 1.65× 高清晰标准 |

| **触觉性格** | 竹笔纸墨（`sharpness 0.45`）：日常按钮不震，盖章三段 `CoreHaptics` | 精密机械游标（`sharpness 0.85`）：刻度吸合清晰利落 | 棉纸与呼噜微振（`sharpness 0.25`）：轻柔不打扰 |

## 三、避免「直接混杂」的融合裁决（针对前期倾向 `A 视觉气质 + B 交互架构 + C 陪伴体验`）

任务书第十三节精辟提醒：**「前期倾向：A 的视觉气质、B 的交互架构、C 的陪伴体验。但不能将三套风格直接混杂，需要统一的最终视觉体系。」**

如果主人拍板走这条「三位一体收敛」路线，**绝不能表面贴 A 纸、里头塞 B 冷灰表格、边上挂 C 光晕**，必须按照以下 **3 条严格统一律（Unified Synthesis Contract）** 融合成唯一一套原创语言：

1. **视觉表面只认「一家之主」（A 的温暖与辨识度为表皮）**：
   - 采用方向 A 的**暖纸色（可选纯白）+ 深墨灰（可选 OLED 纯黑）+ `Clio` 字标与克制朱印「克」**作为全应用唯一的颜色、材质与品牌符号；**不引入**方向 B 的冷工业蓝灰底色，也**不引入**方向 C 的全屏漂浮光晕。
2. **信息架构、扫读纪律与工具结构全走「高能精密引擎」（吸收 B 的骨架，用 A 的颜料画）**：
   - 信息架构完全采用 DS 2.0 统一侧栏与 8+1 设置树；
   - 工具轨迹与审批卡吸收 B 的**左标签右等宽对齐结构 + `2.5pt` 语义左轨 + `.monospacedDigit()` 耗时/Token**，但色彩直接映射到 A 体系已通过 WCAG 校验的语义色（黛蓝进行中 / 竹绿成功 / 琥珀外网 / 朱红风险），**丝毫不显得冷冰冰拼凑**；
   - 动效采用可随时打断、无阻塞、低过冲原则（兼容 A 的从容与 B 的即时打断）。
3. **陪伴、记忆与情感落款落在「非工作打扰区」（吸收 C 的温度，不抢核心工具戏）**：
   - 宠物小克/肉包遵守输入栏上沿水平规则、晨信与日记卡片采用温和包容人文语气、工具完成不搞游戏化连胜绑架；
   - 当用户需要快速看工作结论或审代码时，AI 绝不用“治愈鸡汤”干扰精密信息。

> **原型对照**：随附高保真原型支持在 `AC 定稿（素笺·栖息）/ A 素笺 2.0 / B 清器 / C 栖息` 间对**同一复杂真实长对话、工具、审批、记忆、设置**做 1:1 横评，由主人亲自验证手感后裁定。

## 四、正式定稿方向 `AC`（「素笺·栖息」 Editorial Companion）裁决书

经主人拍板确认（2026-11-25），Clio Design System 2.0 正式采用 **「A 骨 + C 韵 + B 序」的唯一统一视觉与交互语言 `AC`（素笺·栖息 / Editorial Companion）**，彻底消除多套风格混杂：

| 收敛维度 | 正式定稿规范 |
|---|---|
| **1. 品牌符号与审批仪式（取 A 骨）** | 保留 `Clio` 斜体字标、`ClioSeal` 朱印（支持自定义单字落款，默认「克」）与微倾打孔便笺右滑 3 段 `thud()` 盖朱印审批仪式；UI 控件保持系统 SF Pro + 苹方，正文支持书卷/苹方/文楷等自选字体。 |
| **2. 双头牌主色盘与静态光氛（融合 A+C）** | 主色默认 **暖米纸 + 黛蓝（`素笺黛蓝`）**，并将 C 的 **燕麦纸 + 静谧松绿 + 陶土暖（`栖息松绿`）** 升格为同级头牌色盘，设色里 1 键切换；两套均经 Light/Dark/OLED **WCAG AA ≥ 4.56:1** 实测；顶底静态悬浮栏加入 C 的极轻微 `Ambient State Glow`（减透明/减动效自动降级为 `1.5–3pt` 顶部细线，绝不进入滚动正文列表）。 |
| **3. 骨架、工具与动效触觉秩序（藏 B 序，写 C 话）** | 折叠态工具过程采用 **C 的温和中文叙事一句**（如「正在温和并行为你翻阅 3 份资料 · 0.62s」），展开使用 `2.5pt` 语义左轨与左标签右等宽秒数对齐；全局实行 **8+1 全 Push 设置树**、侧栏 1-tap 记忆与跨库搜索、4 档可打断物理弹簧与「普通按钮默认不震」。 |
| **4. 对话正文双方头像 (`chat.faces`)** | **默认关闭（保最大阅读留白）**，并在聊天右上 `⋯` 菜单与设置›外观提供 1 键显隐开关；开启后助手 `32pt` 圆形头像+定制名置顶于回复上方（不占表格与代码宽度），我的 `32pt` 头像贴于右气泡旁，**点击正文双方任一头像直接弹出对应身份编辑页**。 |
| **5. 身份与陪伴宠物解耦** | **助手身份**（名字/定位/专属朱印字/头像模式：`跟随宠物`或独立选宠·单字圆章·相册）与 **我的身份**（称呼/单字圆章·宠物·相册）均完全可定制；**陪伴宠物**（小克/肉包 + 规划新增玄猫/松雀/纸鹤 + 自定义包与单图呼吸）仅以 **6 项克制高频选项** 提供真定制，严守「只站输入框上沿、仅可左右水平拽」规则。 |
