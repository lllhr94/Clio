# Clio Design System 2.0：Spacing & Layout 空间、栅格与布局规范（Deliverable #13）

> 兼容基准：iPhone SE (375pt) · 标准 (393–402pt) · Pro Max (430–440pt) · iPad 分屏 (Compact / Regular)

---

## 一、常用间距与水平留白标准（对齐任务书第八节）

| Token | 基准值 (pt) | 随 `UIScale` | 用途 |
|---|---|---|---|
| `Space.xs` | `4` | ✅ | 图标与徽章内边距、胶囊极紧间隙 |
| `Space.s` | `8` | ✅ | 同组控件内间隙、列表主副标题间距 |
| `Space.m` | `12` | ✅ | 卡片内部模块间隔、输入框悬浮外距 (`Bar.edge`) |
| `Space.l` | `16` | ✅ | 卡片水平/垂直内边距 (`padding`) |
| **`Space.page`** | **`20`（允许范围 `18–24pt`，SE 窄屏 `18pt`）** | ✅ | 全局一级页面左右页边距与正文阅读水平边距 |
| `Space.xl` | `24` | ✅ | 分组卡片之间的纵向呼吸分隔 |
| `Space.xxl` | `32` | ✅ | 页面顶部区块区隔、空态留白 |
| `minTouchTarget` | **`44 × 44 pt`** | **❌ 不随界面缩放减小** | 所有可点控件的 `contentShape` 最小触控热区 |
| `hairlineWidth` | **`0.5 pt`** | **❌ 保持物理精细度** | 全应用分割线与极轻发丝框 |

## 二、同心圆角与非对称安全公式

$$R_{\text{inner}} = \max\bigl(8,\ R_{\text{outer}} - \text{padding}\bigr)$$

- **控件胶囊化**：单行操作按钮、Chip 状态标签、搜索栏、顶部/底部玻璃胶囊 bar **一律 `Capsule(style: .continuous)`**；
- **方形功能图标徽标 (`IconBadge / BrandIcon`)**：比例随语言微调（A `0.26×` / B `0.24×` / C `0.28×`）；
- **旅伴头像**：一律正圆（`Circle()`）。

## 三、界面密度与键盘-宠物空间协同规则

1. **三档独立 UI 密度 (`uiDensity`)**：通过调整行距与列表行纵向留白实现（`高密度 44–46pt 行高 / 标准 52pt / 舒适 58pt`），不牺牲任何按钮的 `44×44pt` 触控容错。
2. **禁止堆砌嵌套卡**：AI 对话回复正文零卡片包裹，直接平铺于版面纸面，仅代码块/表格/引用/工具Trace/批准卡片使用单层小圆角块。
3. **键盘 1:1 跟手与宠物绝对位置红线**：
   - `ChatListViewController` 保持 `keyboardSpacerView` + `CADisplayLink` 同步键盘收放；
   - `PetStage` 永远只站在输入框（或上方悬浮 Dock 卡）顶沿做**水平拖动**（拖起最高离沿 `28pt`，松手回弹落回），**绝不挡住「到最新」跳转按钮或最后一条回复操作条**，也绝不允许钉在屏幕中部遮挡正文选字。
4. **多尺寸窗口禁止硬编码**：禁用 `UIScreen.main.bounds`，全部组件通过 `onGeometryChange` 读取当前容器宽，确保 iPad 台前调度、分屏与横竖屏安全。

## 四、三套语言空间性格差异表

| 布局项 | 方向 A：**素笺 2.0** | 方向 B：**清器** | 方向 C：**栖息** |
|---|---|---|---|
| **外层卡片 / 内块 / Sheet 圆角** | `26 / 14 / 34 pt` | `18 / 10 / 28 pt` *(更锐利克制)* | `28 / 14 / 36 pt` *(更饱满柔和)* |
| **导航与工具密度** | 标准舒展（列表行 `52pt`） | 精密紧凑（列表行 `48pt` + 双列对齐字段） | 呼吸宽裕（列表行 `54pt`） |
| **弹出页标题栏** | 居中简明标题 + 右「完成」胶囊 / 表单「取消 · 保存」 | 同左（附精确状态数字副标） | 同左（标题略放宽呼吸） |

## 五、对话正文双方头像版式规范 (`chat.faces`)

1. **默认态与 1-tap 入口**：
   - 默认保持 **关闭 (`false`)** 以保障单聊长文最大阅读留白与横宽；在**聊天顶栏 `⋯` 菜单**和**设置 › 外观与阅读**均提供显眼的一键开关，所见即所得。
2. **开启后的空间不挤压规则（参考 [ChatPage+Faces.swift](../../../App/Sources/Reading/ChatPage+Faces.swift) 与 [ChatProseRenderer.swift](../../../App/Sources/Reading/ChatListUIKit/ChatProseRenderer.swift)）**：
   - **助手行**：`32×32pt` 圆形头像 + 定制助手名作为轻量行首**置于回复正文上方**，不占用左侧栏宽，长文、代码块与宽表格仍享满宽渲染。
   - **我的行**：`32×32pt` 圆形头像（[MeAvatar.swift](../../../App/Sources/Pet/MeAvatar.swift)）贴于右对齐气泡外侧；用户气泡最大宽度严格扣减 `faceSize + 8pt`，保证 AX3 大字下右侧零裁切。
   - **连续归并 & 时间戳**：同一说话人连续多段仅首段展示头像；跨 30 分钟对话自动在段间居中插入 `.tabularNums` 时间戳。
   - **正文即入口**：直接点击正文中的助手头像/名字或我的头像，就地唤起对应身份编辑面板。
