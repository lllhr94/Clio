## 一、Clio `batch-0.36` 现有色盘实测缺陷 vs 2.0 修复基线

经 Python 线性对比度实测，`batch-0.36` 原版 [Ink.swift](../../../App/Sources/Design/Ink.swift#L234-L387) 存在 4 处显性合规硬伤（均已在 DS 2.0 三套色盘中根治）：

- 浅色纸面 `#F6F1E7` 上：`inkFaint #A8A294` 对比度仅 **`2.26:1`**（严重不达标）；`warn #C08A3E` 仅 **`2.69:1`**；`ok #5E8C6A` 仅 **`3.43:1`**（小字不及格）。
- 深色 `#1C1A17` 上：`inkFaint #6E685D` 仅 **`3.14:1`**（小字不及格）。

同时对任务书第十三节 3 组**候选视觉草图色板**进行了实测审计：A 组 `#858575 (3.47:1)`、B 组 `#727A86 (4.18:1)` 与 `#338977 (4.07:1)`、C 组 `#738A70 (3.41:1)` 在浅底上作为小字文本均未达到 AA 4.5:1。**DS 2.0 保留三者原始色相氛围，但将全部承担文字职责的语义色统一调校到 `≥ 4.56:1`。**

## 二、通用语义色阶树（Semantic Token Tree）

全应用组件只引用语义 Token（`tools/lint.py` 自动禁止业务代码写裸 `Color(hex:)`）：

| 语义角色 | 用途定位 | AA 合规基线 |
|---|---|---|
| `bg` (L0) | 全局底层画布（聊天背底、设置背景、侧栏底） | — |
| `surface` (L1) | 卡片与分组行底（`RowCard`、`InlineAsk`、工具卡） | 与 `bg` 在 OLED 模式仍保 `4–7%` 灰阶差，不融黑 |
| `surfaceElevated` (L2) | 弹出 Sheet、模型切换单、浮窗预览、减透明兜底层 | — |
| `surfaceSubtle` (L3) | 代码块、行内代码、我的消息、输入框槽、标签洗白底 | — |
| `ink` | 主正文、H1–H3、核心标题、主文字 | 对 `bg`/`surface` **≥ 13.4:1** |
| `inkSecondary` | 副标题、思考过程正文、说明文本 | 对 `surface` **≥ 7.2:1** |
| `inkTertiary` | 脚注、时间、刻度数字、日常旁注 `L.hint` | 对 `subtle` **≥ 4.56:1** |
| `rule` | `0.5pt` 分割线与卡片发丝描边 | `Increase Contrast` 下自动加重至 `1pt` |
| `accent / onAccent / accentWash` | 核心操作聚焦、活跃开关、已选胶囊、进度条 | 文字对比均 **≥ 6.4:1** |
| `seal / sealFill / onSeal` | 方向 A 朱印落款；方向 B/C 对应核心授权徽章色 | 均达 **≥ 4.91:1** |
| `ok / warn / danger / stopWash` | 成功/安全、外网 `Taint` 警示、拒绝/报错 | 均 **≥ 5.53:1**，且强迫与图标+文字共现 |

## 三、iOS 26 Liquid Glass 使用红线（守住 120Hz 与阅读纯净度）

遵循 **Apple HIG Materials (`Don't use Liquid Glass in the content layer`)**：
1. **允许使用真实 `.glassEffect(.regular, in:)`**：悬浮顶栏胶囊组、悬浮底部输入框背板、右下方跳转圆形浮钮、全屏审批浮条。顶/底玻璃控件后必须垫一张同色 `bg → clear` 垂直渐隐带，防止长文穿过产生硬黑分割条。
2. **绝不在滚动聊天内容层用真玻璃**：消息气泡保持轻量渐光描边 `glassBubble`；代码块/引用/表格使用纯静态 `surfaceSubtle / codeBg`，确保 120Hz 滚动稳如磐石。
3. **无障碍兜底**：开启系统 `Reduce Transparency` 时，全部玻璃切换为 `surfaceElevated (98%)` + `1pt rule` 实框。

## 五、定稿方向 `AC`（「素笺·栖息」）双头牌色盘与静态 `Ambient State Glow`

1. **双头牌主色盘同级并列**：
   - **`素笺黛蓝 (paper_dai · 默认)`**：直接复用已校验通过的 A-Light / A-Dark / A-OLED（最低配对 **4.58:1**）。
   - **`栖息松绿 (oat_pine · 同级头牌)`**：直接复用已校验通过的 C-Light / C-Dark / C-OLED（燕麦雾白 + 静谧松绿 `#276454` + 陶土暖 `#9A492B`，最低配对 **4.56:1**）。两套色盘共享完全一致的组件骨架、圆角和字体规则，彻底消除混杂割裂。
2. **静态 `Ambient State Glow`（仅限静态顶底栏层）**：
   - 在顶部安全区之下渲染低饱和微光（空闲=`accent`、思考/流式=`warn`、等待审批=`seal`、断网报错=`danger`），**严格禁用在滚动列表 Cell 中**，保障 120Hz 零掉帧。
   - 当用户开启系统「降低透明度 (`Reduce Transparency`)」或「减弱动态效果」时，自动切换为静态顶部 `1.5–3pt` 高对比语义细线。
