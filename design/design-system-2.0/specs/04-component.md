## 二、Iconography（图标语言规范）

1. **统一采用 SF Symbols 5+ 分级语义体系**：
   - **列表前置徽标 (`IconBadge`)**：圆角方形底（`R = size * cornerRatio`）+ 高对比白字填充符号 `.symbolVariant(.fill)`，遵循行业识别色彩分类（黛=模型、藤=外观、墨=对话、胭=旅伴记忆、缃=工具、竹=安全隐私、浅灰=关闭/禁用）。在方向 B 可选冷静单色微边框风，但同界面绝不混搭两套风格。
   - **顶部/底部栏工具图标**：统一线型描边 `weight: .medium / .semibold`，尺寸锚定 `Ink.Size.body / title`，禁止同排出现一个极粗黑一个极细线。
   - **第三方服务商图标 (`BrandIcon`)**：维持运行时按需拉取并落盘手机本地缓存，**绝不把商业公司 Logo SVG/PNG 提交进代码仓库**。
2. **颜色 + 形状双编码**：所有状态图标（成功勾、失败叉、未知问号、外网盾牌、安全锁）必须使用语义明确的轮廓形状，不可仅凭单色圆点变色区分。

## 三、Illustration, Identity & Pet（插画、身份定制与宠物规范 · 定稿 `AC`）

1. **唯一角色资产体系（宠物包 schema 1）**：
   - 现有内置 **小克 (`xiaoke`) / 肉包 (`roubao`)** 与后续规划新增原创 **玄猫 (`xuanmao`) / 松雀 (`songque`) / 纸鹤 (`zhihe`)**，连同用户导入 `.zip` / `.gif` / 单图包（单图自动附柔和呼吸动画），共同构成唯一宠物资产层。
   - 像素宠物使用最近邻硬边放大（`interpolation(.none)` + `displayScale` 整数倍对齐），绝不加高斯模糊，保持如《谜底时钟》和原版一样锐利的像素边缘。
2. **「伴读立宠」与「助手 / 我的身份」解耦定制**：
   - **助手自定义**（[CardEditors.swift](file:///f:/work/Antigravity/Clio/App/Sources/Reading/CardEditors.swift)）：独立编辑名字、一句话定位、**专属朱印单字**，以及 4 种头像模式：**跟随当前宠物 / 指定哪只宠物 / 自定单字与纸墨底色圆章 / 本地相册照片**。
   - **我的自定义**（[MeAvatar.swift](file:///f:/work/Antigravity/Clio/App/Sources/Pet/MeAvatar.swift)）：独立设定我的称呼、单字圆章、宠物头像或相册照片。
   - 默认开启「助手头像跟随宠物」，但允许用户一键关掉联动——实现「输入框站松雀、正文用真人或另一只头像」。
3. **陪伴宠物 6 项克制必要自定义（拒绝臃肿养成废设置）**：
   - ① 选伴读伙伴 & 改昵称 + 全状态动作试看；② 头像联动开关；③ `StopRow` 体型档位（75% / 100% / 125% / 150%）；④ 站上输入框开关 + 一键「歇 1 小时」；⑤ 互动活跃度 3 选 1（活泼冒泡 / 安静只动作 / 极简仅待批与出错动）；⑥ 按不同助手独立绑定默认伴读宠。
4. **品牌标志图形（定稿 `AC`：A 骨 + C 韵）**：
   - 保留侧栏「`Clio` 斜体字标 + `ClioSeal` 朱印」与打孔便笺右滑盖章落款；顶底静态栏融入 C 的柔和 `Ambient State Glow` 与旅伴呼吸环。
   - 引导页像素插画限制最大边长为 `min(w*0.52, h*0.28)` 居中排布，下方文字保持左对齐清晰可扫读。

## 四、全组件 8 态统一契约（State System）

全应用任何可交互卡片、按钮、列表行与面板，必须显式覆盖以下 8 种状态并遵循统一样式逻辑：

| 状态 | 视觉与交互表现规范 | 禁止事项 |
|---|---|---|
| **1. Default** | 语义表面底（`surface` / `bg`），主字体清晰达到 AA ≥ 4.5:1。 | 禁止页面级私设阴影半径与随机透明度。 |
| **2. Pressed** | 统一 `PressStyle`: `scaleEffect(0.97)` + `opacity(0.85)` + `Motion.instant` 弹性回弹。 | **普通按钮默认不震动**；禁止个别页面缩 `0.88` 造成失重感。 |
| **3. Selected** | 选中项切为 `accentWash` 底 + `accent` 字色/边框（或反白 `accent` 底 + `onAccent`），VoiceOver 注入 `.isSelected`。 | 禁止仅靠文字微变细灰而毫无框底/图标区分。 |
| **4. Disabled** | 整体透明度与字色降为可辨识低对比但保留边界，触屏事件和触觉立即静音禁用。 | 禁止点击后无任何反应也无原因提示（主按钮需解释缺失前提）。 |
| **5. Loading / Streaming** | 控件内嵌 `.mini ProgressView`；长文流式采用零重排预留空间或高度裁剪动画（`ThinkingBox / PlanReveal`）。 | 严禁流式文字叠加 Fade 导致三层重影或滚动跳底。 |
| **6. Error / Warning** | 使用 `stopWash / warn` 语义底条 + 明确警示图标 + 一句人话原因 + 1-tap 修复或重试入口。 | 严禁只弹冰冷 HTTP 状态码 `502 / -1009`。 |
| **7. Empty** | 居中轻量象征图标 / 小克或题目 `Inscription` + 一句明确解释 + 常见 starter 操作芯片。 | 严禁大面积纯白/纯黑死寂空白让用户误以为卡死。 |
| **8. Offline / Degraded** | 顶部状态横幅或输入框提示「当前无网络，本地记忆与书案仍可查看与离线浏览」，高亮受限操作不闪退。 | 严禁断网点击模型后无限转圈不超时报错。 |
