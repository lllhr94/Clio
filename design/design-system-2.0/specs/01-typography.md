## 一、9 项独立排版与阅读控制维度（必须解耦，禁止绑定混算）

遵循任务书第八节要求，将原本耦合在少数滑杆中的参数彻底独立为 9 个可控字段（均走 `StopRow`/`StopRuler` 或选择行，**禁用 Stepper/Slider**）：

| # | 独立控制项 | 允许取值（初始推荐试验标尺） | 影响范围 |
|---|---|---|---|
| **1** | **界面字号 (`UIScale`)** | 紧凑 `0.88×` · 偏小 `0.94×` · 标准 `1.00×` · 偏大 `1.08×` | `Ink.Size` 五档 UI 控件、行高与外框内距（**正文另走独立控制**） |
| **2** | **正文字号 (`readingSize`)** | `15` / `16` / **`17`（默认）** / `19` / `21` / `24 pt` | AI 正文、用户消息、书案长文、手札正文 |
| **3** | **正文字体 (`readingFace`)** | 书卷 (Serif+苹方) / 苹方 / 圆体 / 文楷 (`ClioKai-Medium`) / 宋体 / 楷体 | 阅读轨全部文字；按需字体由 `FontShelf` 后台下载 |
| **4** | **标题字重 (`headingWeight`)** | 适中 (`Medium`) / **清晰 (`Semibold`, 默认)** / 凝重 (`Bold`) | H1 / H2 / H3 与加粗强调词汇的层级区分度 |
| **5** | **代码字体 (`codeFace`)** | **`Maple Mono + Clio Mono CN`**（2:1 对齐，默认） / 系统等宽 (`SF Mono`) | 代码块、行内代码、终端 `DenPage`、模型名与路径 |
| **6** | **正文行高 (`lineHeight`)** | 紧凑 `1.35×` · 适中 `1.50×` · **舒展 `1.65×`（默认）** · 宽松 `1.80×` | 按统一公式抵消各字体自带固有行高：`max(0, size*m - natural)` |
| **7** | **段落间距 (`paragraphGap`)** | 紧凑 `10pt` · **适中 `13pt`（默认 ~0.72×17）** · 舒展 `16pt` · 宽松 `20pt` | Markdown 段落之间呼吸节奏（避免多段粘连或断层） |
| **8** | **阅读宽度 (`readingWidth`)** | 集中 `560pt` · **平衡 `640pt`（默认）** · 宽阔 `700pt` | iPad/横屏 Pro Max 最大行宽收敛（单行 35–42 汉字黄金眼扫宽度） |
| **9** | **UI 密度 (`uiDensity`)** | 舒适留白 / 标准平衡 / 高密度信息流 | 仅作用于侧栏行间距、工具步骤行与首页卡片内距 |

## 二、全 18 类 Markdown 与富文本元素排版参数矩阵（实测基准）

> 以下参数作为长对话原型与真机 AB 测试初值（来自任务书第八节 & `ChatListModels.swift`），确保**全站风格统一、不把单条回答套成厚重嵌套卡、流式与定稿零闪跳**。

| Markdown / 内容元素 | 字号建议初值 (`17pt` 基准) | 字重与样式规范 | 间距与结构约束 |
|---|---|---|---|
| **一级标题 H1** | **`22–24 pt`（建议 `23 pt`）** | Semibold（可选随第 4 项调字重） | 上方留白 `1.05×`，下方 `0.40×`（解决 0.36 `1.24×=21pt` 与 H2 差距略近的问题） |
| **二级标题 H2** | **`19–20 pt`（建议 `19.5 pt`）** | Semibold | 上方留白 `0.85×`，下方 `0.35×` |
| **三级及以下 H3+** | **`17–18 pt`（建议 `17.5 pt`）** | Semibold / Medium | 上方留白 `0.60×`，下方 `0.30×`，靠字重与左齐区分，绝不用花哨装饰框 |
| **AI 正文 / 用户正文** | **`16–17 pt`（默认 `17 pt`）** | Regular；粗体清晰加重，斜体遵循字体特性，删除线低饱和穿透线 | 行高 `1.55–1.7×`（默认 `1.65×`）；段距 `12–16pt`；AI 正文无外包大卡（去边框），用户消息用轻质感气泡 |
| **有序 / 无序 / 多级嵌套列表** | 同正文 `16–17 pt` | 有序数字强制 `.monospacedDigit()` 防止 `9.→10.` 错位 | 项距 `0.42×`（嵌套子项 `0.25×`），二级圆点用空心/细圆区分层级，保留严谨悬挂缩进 |
| **引用块 (`Blockquote`)** | 同正文或微收 `-0.5pt`，色降为 `inkSecondary` | 极细实底微洗或左侧 `2.5pt` `accent/rule` 竖线 + 小圆角 `R_inner` | 禁止重阴影边框嵌套，引文内支持嵌套粗体与行内代码 |
| **分割线 (`<hr>`)** | 高 `0.5pt` 发丝线 | `rule` 色，居中左右对称留白或占满栏宽 60% | 上下均等 `16pt` 呼吸区 |
| **行内代码 (`inline code`)** | `max(12, readingSize - 2)` | Maple Mono + Clio Mono CN，圆角 `5pt` `surfaceSubtle` 底 | 不破坏整行行高基线（垂直轻微 pad `1.5pt`） |
| **多语言代码块与代码高亮** | **`13–14 pt`（`max(12, readingSize - 3)`）** | 等宽行距 `0.12×` 字号（紧密对齐）；去首尾空行 | `inkBlock` 仅单层小圆角 (`10–14pt`)，不叠双层外框；超宽横向滚动 + 右边缘底色渐隐提示；顶条语言名 + 一键「✓ 已复制」；超长代码块（>18 行）折叠预览 |
| **表格 (`Table`)** | **`14–15 pt`（表头 Semibold）** | 表头轻微底色 `surfaceSubtle`，数值列建议等宽数字 | 独立横向滚动容器不撑破屏幕宽；行高清晰，单元水平内边距 ≥ `12pt` |
| **数学公式 (`LaTeX`)** | 随正文 `17pt` | `SwiftMath` 原生矢量化渲染，公式颜色动态跟随 `Ink.ink` | 行内公式平滑对齐基线；独立公式块超长支持横向平滑滚动 |
| **图片、图表与文件预览卡** | 辅助说明 `12–13 pt` (`meta`) | 图圆角 `R_inner`；文件卡单行图标+文件名+大小/挂载标记 | 图片/HTML 互动预览点击走 `.matchedTransitionSource` 缩放打开 |
| **来源与脚注 (`Sources`)** | `12–13 pt` | 回答末尾聚合为紧凑多图标站点胶囊 `N 个来源` + 脚注锚点 | 严禁学旧式 `[1][2]` 小角标造成 `44×44` 以下误触 |
| **行内链接 (`Link`)** | 同上下文正文 | 主强调色 `accent` + 细微下划线或点击底纹（不单独凭颜色区分） | 长按弹出拷贝/在内置浏览器 `Roam` 中打开 |
| **流式生成与定稿态** | 严格与定稿同字号、同字重、同度量 | **`transaction { $0.animation = nil }` 禁叠影重排** | 流式未闭合语法（代码围栏/表格/粗体）提前预判容错，**定稿瞬间绝不允许高度/字体突变闪跳** |
| **跨段选字、引用追问与朗读** | 原生 iOS 长按选区 (`UITextView` / 可选瓦片转换) | 原生浮动菜单扩展 `引用追问` / `加入拾遗` / `朗读此段` | 选字状态下自动锁住跟底滚动，绝不把正在选的段落冲走 |

## 三、W3C CLREQ 中文排版规则工程规范（已核验 `https://www.w3.org/TR/clreq/`）

1. **行首行尾禁则（§6.1.1 严守避头尾）**：
   - 行首禁止出现句号、逗号、顿号、分号、冒号、感叹号、问号、后括号/书名号/引号（如 `，。、：；！？）》」』】`）；
   - 行尾禁止出现前括号/书名号/引号（如 `（《「『【`）。
   - 采用 **「先挤进后推出」** 优先策略，防止某行出现巨型缺口或孤零零一个标点挂在下一行首；双 em 破折号（`——`）、双省略号（`……`）、数字+单位（`16.5 ms` / `120 Hz`）禁止跨行截断（§6.1.2）。
2. **标点宽度压缩（§6.3.2）**：
   - 连续出现的全角标点（如 `”，`、`。）`）总宽由 `2em` 视觉挤压至 `1.5em`（CoreText `kern` 自动微调），行尾半角留白适度收紧而不使用简体出版不推荐的边缘悬挂（§6.1.3）。
3. **中西文混排光学微距（§6.3.3）**：
   - 汉字与拉丁字母/数字相邻边界注入约 `1/4 em`（实际画面 `0.12em–0.20em`）光学 `kern` 间距；
   - **仅在渲染层 `NSAttributedString` 生效，绝不修改原始字符串、绝不污染剪贴板**；行首行尾、紧邻中文点号（`、` `，` `。`）与成对括号内侧不额外加距。
4. **2:1 等宽代码块对齐（`Ink.codeBlockFonts`）**：
   - 保持 `MapleMono`（ASCII `0.5em` 细胞）+ `ClioMonoCN`（中文 `1.0em`），任意中英混合表格/SSH 终端日志列严格笔直对齐。
