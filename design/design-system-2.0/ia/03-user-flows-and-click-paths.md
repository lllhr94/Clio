## 二、典型复杂流程详拆（以任务 #4 与任务 #6 为例）

### 示例 1：用户想「看看 AI 记住了我什么 + 临时关掉自动记隐私对话」
- **旧版路径（挫败点明显）**：
  1. 聊天页拉出侧栏 → 看不到记忆入口 (`?`)
  2. 点击左下/底部「调弦（设置）」→ 扫一眼 6 个分类，看到「旅伴」
  3. 点「旅伴」→ 滑到旅伴列表最底部才看见「拾遗（长期记忆）」
  4. 进「拾遗」后想关自动写入/夜间整理，还得在右上找 `...` 或开关，前后至少 **4–5 次尝试**。
- **DS 2.0 路径（1 次直达 + 语义分流）**：
  - **路径 A（看/改记忆内容）**：任意处拉出侧栏 → 首屏第 3 个 L1 按钮就是 **`记忆` (`拾遗`)** → 1 tap 直接管理四层（置顶/表面/深层/封存）及导入/搜索。
  - **路径 B（关自动记忆机制）**：点「记忆」页右上齿轮直接进「记忆策略」，或从设置首页 1 tap 进 `旅伴与记忆 › 记忆策略与夜间整理`，开关「自动写入」「自动召回」「夜间整理」。

### 示例 2：换新手机后通过 WebDAV 恢复全量数据与密钥
- **旧版路径**：进首页点设置 → 找到不太直觉的「隐私与安全」→ 打开 1,583 行杂糅的「养护」Sheet → 滑过本地备份与诊断说明找到 WebDAV 区 → 输密码/选文件。
- **DS 2.0 路径**：
  1. 首启引导或设置首页直接出现清晰分组 **「数据与养护」› 「备份与云同步 (WebDAV)」**（新机冷启桌面Checklist同样有直达卡片）。
  2. 页面**首屏即双卡清晰对照**：「① 本地加密打包与导入」vs「② WebDAV 云端同步」，下方独立安全提示明确告知 **「仅当开启密钥加密且设置独立口令时才含 API 密钥；密码匣秘钥遵守最高隔离规则」**。
  3. 选中历史快照 → 弹出标准 iOS 解锁口令 Sheet（支持密码自动填充保护）→ 校验完成后一键恢复重启。

## 三、新用户首 10 分钟迷失度检查（书卷词典风险控制）

| 书卷高频词 | 无旁注认知障碍评分（主观推演） | DS 2.0 防迷失设计 |
|---|---|---|
| **拾遗 / 调弦** | **高**（新用户无法凭直觉猜出对应「记忆 / 设置」） | **① 日常模式与书卷模式平等可选**（首启直观展示双卡片对比预览）；<br>**② 开启书卷模式时默认打开 `L.hint` 日常旁注**（如 `拾遗 (记忆)`、`调弦 (设置)`，字色通过 AA 对比度校準）；<br>**③ 搜索全库双语+英文全匹配**，搜 `"设置"` / `"记忆"` / `"memory"` 一样命中 `调弦` / `拾遗`。 |
| **斗室 / 远山 / 远游** | **中**（语义诗意，但初次使用易混淆本地与远程） | 分入统一 **工作台** 模块并配准确系统图标（`terminal` / `server.rack` / `safari`）+ 功能一句话解释副标题。 |
| **便笺 / 候印** | **低**（聊天内伴随明显红色/琥珀安全框和动效，一望即懂） | 保留强结构化字段 +「同意/拒绝」清晰按钮文案（严守 `AGENTS.md`：**按钮保持日常直白说法**）。 |
