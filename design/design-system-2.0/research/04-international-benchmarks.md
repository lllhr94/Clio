## 1. Bear (熊掌记)

- **产品定位与分级**：极简轻量 Markdown 笔记与长文写作工具（Shiny Frog）。**分级：`🏆 官方获奖产品`**（2016 Mac App of the Year；2017 Apple Design Award 得主）。
- **证据来源清单**：
  - `[官方获奖记录]` `[实测视觉核验]` Bear 官网 `https://bear.app/`（实测加载）与 Apple 官方获奖归档（2016 Mac App of the Year、2017 Apple Design Award）：直接观摩其纯白纸张画布、深海蓝灰（`#2A2C2E`–`#1E2430`）主题抽屉、珊瑚红与绿点缀、行内 `#hobby/3D printing` 药丸标签、带 1px 细边的 `"Working theory"` 提示卡及左/右顶角圆润悬浮气泡按钮（返回、`i`、`•••`）。
  - `[待真机实录补全]` 实机长文键盘快捷键 bar 滚动阻尼曲线。
- **完整端到端操作流程分析**：
  1. **三栏渐进推入**：极简「标签栏 → 笔记列表 → 沉浸编辑器」经典三栏架构，手势右滑退回，左滑收拢。
  2. **所见即所得混合 Markdown**：输入 `**`、`#`、代码块语法瞬间格式化渲染，支持隐藏语法符号保持纸面干净。
  3. **多主题切换与导出**：支持从温暖纸色（Dieci/Panic/Red Graphite）到 OLED 纯黑的多套阅读/写作调色盘；一键导出 PDF/HTML/Markdown。
- **12 维度逐项拆解**：
  1. **中文排版**：字号/行高/段距/行宽（Line Length）比例堪称写作用品黄金标准，标点与代码块混排整洁。
  2. **信息密度**：三栏之间信息递进极其克制，笔记列表仅「标题 + 两行摘要 + 标签/图片缩略」。
  3. **布局对齐**：编辑器左右边距随屏幕宽度自适应，保证单行阅读字符数舒适（约 60–75 字符等价宽）。
  4. **视觉层级**：单色高识别度品牌点缀（朱红/特定主题色）+ 中性灰底，毫无视觉吵闹感。
  5. **设计一致性**：十余种预设调色盘全部由设计师精细校准对比度与语法高亮协调性。
  6. **原生交互**：iOS 原生侧滑返回、键盘顶栏格式化工具条、拖拽多选批量加标签极为丝滑。
  7. **微动效**：折叠章节、清单打勾、三栏推拉稳重安静。
  8. **触觉反馈**：轻量克制，仅在勾选待办与重排操作给确认震动。
  9. **动画打断**：原生 Navigation / 三栏手势 100% 随时可逆打断。
  10. **跟手性**：纯原生 AppKit / UIKit 文本引擎，长文档滚动跟手无延迟。
  11. **无障碍**：完美响应系统 Dynamic Type 与 VoiceOver 焦点流。
  12. **性能与 120Hz 开销**：自研轻量 TextKit 渲染，万字笔记零卡顿。
- **Clio 落地三段论**：
  - **值得借鉴什么**：①**「精心校准的整套调色盘哲学」**：每种主色连带轻微调节行高/分隔线/代码块着色，而不是粗暴只换一个按钮颜色（Clio 已有 `Ink.Palette` 的 `tint` 混色设计，可进一步把代码高亮与分隔线语义纳入调优）；②**隐藏 Markdown 语法符号的干净呈现 + 舒适最大行宽限制**；③**极简笔记列表三要素**（标题+两行摘要+状态点）。
  - **不应该照搬什么**：嵌套无限 `#标签/子标签` 侧栏不适合 Clio 多助手/多对话场景（Clio 坚持浅平置顶+对话+颜色标签）。
  - **如何应用到 Clio**：直接优化 `StudyPage.swift` Markdown 预览阅读器、`DeskSidebarView.swift` 行摘要信息比例，以及 `Ink.Palette` 在方向 A（素笺 2.0）下的配色精修。

## 2. Day One

- **产品定位与分级**：全球标志性个人私密日记与多维记忆档案应用（Automattic / Bloom Built）。**分级：`🏆 官方获奖产品`**（2012 Mac App of the Year；2014 Apple Design Award 得主）。
- **证据来源清单**：
  - `[官方获奖记录]` `[实测视觉核验]` Day One 官网 `https://dayoneapp.com/`（实测加载）及 2014 ADA / 2012 Mac App 官方归档：实测核验其天蓝（`#44C0FF`）顶部渐隐渐变落入纯白列表画布、极简顶栏（菜单 + 日志切换器 + 圆形筛选钮）、按月日分组时间轴卡片及右下角圆形 `+` 浮钮。
  - `[待真机实录补全]` 实机大相册时间轴快速滚动预解码性能曲线。
- **完整端到端操作流程分析**：
  1. **多视角回忆入口**：底部清晰区分「时间轴 / 日历 / 媒体 / 地图」，顶部常驻「历史上的今天（On This Day）」回顾卡。
  2. **沉浸记录**：点击「＋」直接拉起今日模板与自动附加的天气/位置/步数元数据。
  3. **隐私守护**：切出后台自动触发模糊遮罩 + Face ID 解锁。
- **12 维度逐项拆解**：
  1. **中文排版**：长文本日记与诗意引导文排版舒适，元数据（时间/地点/天气）缩成一行极淡灰色脚注。
  2. **信息密度**：时间轴按日分组，左日期块右摘要卡，阅读节奏从容。
  3. **布局对齐**：左窄右宽日期时间轴对齐极其经典，多图拼贴自动规整对齐。
  4. **视觉层级**：正文与照片占主导，时间/天气/地点退居二线做氛围陪衬。
  5. **设计一致性**：深蓝/海蓝品牌主色与温润纸白卡片多年保持高度辨识度。
  6. **原生交互**：Face ID 解锁无缝、日历上下联动、原生 Share Extension 快速收集。
  7. **微动效**：卡片展开与历史回顾卡切换温和舒缓。
  8. **触觉反馈**：轻量系统级确认。
  9. **动画打断**：常规手势退场支持可逆。
  10. **跟手性**：十年以上的原生 iOS 列表优化，时间轴极长仍顺滑。
  11. **无障碍**：VoiceOver 对日期标题与天气元数据朗读清晰。
  12. **性能与 120Hz 开销**：媒体缩略图多级缓存成熟，滚动无白块闪烁。
- **Clio 落地三段论**：
  - **值得借鉴什么**：①**「On This Day / 记忆回顾与手札时间轴」**：让个人记忆和每日手札不再躺在数据库里吃灰，而是以优雅的时间轴卡片浮现；②**自动环境元数据一行浅灰脚注**（天气/时间/地点不抢正文）；③**切后台隐私遮罩 + 面容解锁**。
  - **不应该照搬什么**：富媒体旅行日记式的九宫格照片流与多本独立日记簿切换。
  - **如何应用到 Clio**：直接优化 `Daily.swift`（晨信与手札的时间轴归档呈现）、`MemoryReviewHistory.swift`（夜间整理记录时间轴）以及 `AppLock.swift` 切后台模糊防护遮罩。

## 3. Ulysses

- **产品定位与分级**：面向长篇创作者的无干扰专业写作环境。**分级：`🏆 官方获奖产品`**（2016 Apple Design Award 得主；多届 App Store / Mac App of the Year 提名与精选）。
- **证据来源清单**：
  - `[官方获奖记录]` `[实测视觉核验]` Ulysses 官网 `https://ulysses.app/`（实测加载中文版）：视觉验证暗炭灰三栏侧边库（发丝线分割 + 彩色分组图标）、左列弱化灰调 `##` Markdown 标记、悬浮柔灰字数目标弹窗（`"4,833字 / 6,000字"` + 天蓝圆环进度指示）及行内校对浮泡（`"两位"` / `"忽略"`）；2016 Apple Design Award 得主。
- **完整端到端操作流程分析**：
  1. **零工具栏专注书写**：打开文稿键盘呼出后，界面四周只留纯净纸面与极微弱字数/目标进度小环。
  2. **快捷统计与大纲抽屉**：向内侧滑或点顶部小指标，即时滑出大纲与关键词/可读性统计卡片。
  3. **多格式排版导出**：一键切换多种出版预设（书稿/论文/电子书）实时渲染并导出。
- **12 维度逐项拆解**：
  1. **中文排版**：讲究极致的中文阅读宽容度与舒适段距，内置多种专业衬线/无衬线写作字体组合。
  2. **信息密度**：写作态极致低噪，管理态结构清晰。
  3. **布局对齐**：黄金比例单栏阅读宽度与左滑大纲抽屉对齐工整。
  4. **视觉层级**：弱化 Markdown 标记颜色（低饱和灰蓝/浅琥珀），确保作者视线聚焦在文字本身而非语法符号。
  5. **设计一致性**：十余年打磨出极统一的「纯粹书写工作台」语言。
  6. **原生交互**：左右滑切换抽屉层级、键盘上栏定制光标移动/快捷插入条高效顺手。
  7. **微动效**：字数目标圆环填满瞬间的温和点亮提示。
  8. **触觉反馈**：达成写作目标与滑动抽屉吸附有微轻震。
  9. **动画打断**：侧滑层级随时可拖停与退回。
  10. **跟手性**：手势滑出大纲/统计层跟手顺滑。
  11. **无障碍**：动态字号与朗读校对体验扎实。
  12. **性能与 120Hz 开销**：长篇连载万字不卡，打字零延迟。
- **Clio 落地三段论**：
  - **值得借鉴什么**：①**低饱和度语法标记哲学**：代码块、链接、加粗标识和行内引用不应喧宾夺主；②**极简圆环进度指示**（Clio 上下文用量与字数达标感）；③**零干扰长文写作/阅读容器**。
  - **不应该照搬什么**：专业出版长篇多文稿组卷功能。
  - **如何应用到 Clio**：优化 `Ink.Code` 语法着色在深浅纸底上的低饱和协调度，以及 `ChatWorkingBar` / `ChatPage+Dock` 里上下文占用的极简微圆环。

## 4. Stoic (情绪日记与正念引导)

- **产品定位与分级**：结合斯多葛哲学、情绪追踪与呼吸仪式的极简日志应用。**分级：`📐 业内设计参考`**（获 App Store Editors' Choice 长期推崇，无官方 ADA / App Store 年度主奖核验记录）。
- **证据来源清单**：
  - `[App Store 官方截图/预览]` App Store Stoic 页面（黑白极简对比、卡片式晨间/晚间引导、呼吸圆环）。
  - `[公开交互演示/评测]` 设计专栏对 Stoic 单色版画风与情绪卡片流的拆解。
  - `[待真机实录补全]` 情绪滑块阻尼与呼吸振动实测。
- **完整端到端操作流程分析**：
  1. **晨间/晚间仪式入口**：每日分「Morning Preparation / Evening Reflection」两段卡片引导。
  2. **情绪滑杆与反思输入**：用极简线条滑块标定当下心境，顺次翻过 2–3 张引导卡片完成输入。
  3. **沉淀归档**：落库后转为极简黑白卡片时间线，随时可调出哲学名言。
- **12 维度逐项拆解**：
  1. **中文排版**：中文字体搭配冷峻黑白高对比与优雅衬线引言，具「哲思手账」高级感。
  2. **信息密度**：单屏极低密度，绝不堆砌按钮。
  3. **布局对齐**：大卡片上下居中和规整极简线条构图。
  4. **视觉层级**：高反差墨黑与纯白主导，几乎不靠彩色，仅靠字重、间距与细边框区隔。
  5. **设计一致性**：黑白版画气质贯通图标、插画、按钮与设置页。
  6. **原生交互**：左右滑卡、底部大胶囊按钮明确聚焦。
  7. **微动效**：卡片推进平滑克制，呼吸几何图形稳定展开。
  8. **触觉反馈**：滑动情绪刻度、切换开关有清晰细腻颗粒震动。
  9. **动画打断**：滑卡翻页手势随时可停拉回。
  10. **跟手性**：卡片拖拽阻尼稳重。
  11. **无障碍**：高反差黑白文字对比度极高，极少色彩编码依赖。
  12. **性能与 120Hz 开销**：矢量极简视图，帧率极高且省电。
- **Clio 落地三段论**：
  - **值得借鉴什么**：①**不用彩色堆砌也能做出高级层次**：靠纯墨阶（ink / inkSoft / inkFaint）、留白与 `0.5pt` 细线建立权威秩序（Clio 调色盘里的「墨」与方向 A、方向 B 都可直接受益）；②**极简「晨信 / 日课」分步卡片仪式**。
  - **不应该照搬什么**：全黑白无色系会削弱工程场景里「成功/警告/外网污点/拒绝」的快速危险辨识度——Clio 安全审批区必须保留明确语义预警色！
  - **如何应用到 Clio**：优化 `SetupView.swift` 四步引导页卡片仪式与 `Daily.swift` 晨信/手札分步阅读态。

## 5. Structured (可视化日程时间轴)

- **产品定位与分级**：将待办与日历融合为单条竖向时间轴的日程规划器（unorderly GmbH）。**分级：`🏆 官方获奖产品`**（2025 App Store Award Finalist — iPad App of the Year；实测 `https://developer.apple.com/design/awards/` 核正：**2026 Apple Design Award Finalist — Inclusivity（包容性类别入围，并集成 Foundation Models）**）。
- **证据来源清单**：
  - `[官方获奖记录]` `[实测视觉核验]` Apple Design Awards 2026 实时页面（`https://developer.apple.com/design/awards/`）与官网 `https://structured.app/`（实测加载）：视觉验证其浅灰底上纯白大圆角时间轴面板、珊瑚粉激活日胶囊（`#F28B82`）、顶栏 7 日带彩点日程带、当前时间进度提示（`9:41` + `19 min remaining`）、竖向长条胶囊块、虚线「`30min of free time?`」空档卡与右侧空心完成圆环。
- **完整端到端操作流程分析**：
  1. **视觉化日程流**：竖直时间轴直接把日程画成与时长成正比的圆角胶囊条，中间空档自动标出「X 小时空闲」。
  2. **零压新增与拖拽调整**：点空闲缝隙直接插入该时段任务；长按任务条沿时间轴上下拖动改期，实时吸附 15 分钟刻度。
  3. **完成反馈**：轻点左侧圆圈完成，任务柔和变淡沉底。
- **12 维度逐项拆解**：
  1. **中文排版**：任务标题与副标题时间区间（`09:00–10:30 · 90m`）排版紧凑直观。
  2. **信息密度**：高可读性的可视化时间块，比传统格子月历/密集列表更省脑力。
  3. **布局对齐**：左侧竖轴连接线精准串联图标圆泡与右侧胶囊卡。
  4. **视觉层级**：当前正在进行的任务块微亮放大，过去任务自动淡化退后。
  5. **设计一致性**：柔和马卡龙/低饱和粉彩气泡配统一圆形图标，视觉低压力。
  6. **原生交互**：沿时间轴长按拖动改时间、系统日历双向同步流畅。
  7. **微动效**：拖动跨越刻度时图标微弹，新建任务沿轴展开顺滑。
