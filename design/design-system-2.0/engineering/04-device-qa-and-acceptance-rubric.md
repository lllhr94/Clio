## 二、11 项「一票否决」红线检查（出现任意 1 项直接打回重改）

| # | 一票否决项 | 真机核验动作 |
|---|---|---|
| **1** | **聊天明显卡顿或跳位** | 载入 ≥ 80 轮图文+表格+代码混合长对话，快速上下甩屏，开启 `CarePage` 内 `FrameMeter / Hitches` 记录观察 |
| **2** | **流式生成与定稿发生明显闪烁** | 让模型输出包含 2 个代码块与 1 张 5 列宽表格的回答，盯紧 `Streaming → Settled` 完成一瞬间高度与字体是否闪跳 |
| **3** | **键盘弹出造成消息异常位移** | 在长对话底端、历史中段分别点输入框弹起再交互下拉关闭键盘，观察末句与输入栏间距是否始终一致 |
| **4** | **宠物阻挡正常操作** | 输入长草稿叠加 `PlanCard` 与 `RoamSlip`，打开小克拖拽至最右/最左，测试「回到底部」「发送」「最后一条复制/引用」均能 100% 点中 |
| **5** | **误触或绕过安全审批** | 先让模型读外网页面再触发发邮件/写文件，确认 `Taint` 强制拦截有效且不可勾选常驻跳过；Quick-swipe 滑到 `70%` 松手必须回弹不授权 |
| **6** | **文字截断** | 切换 iOS `设置 › 辅助功能 › 更大字体 (AX3)`，全页遍历首页、侧栏、聊天顶栏、审批卡、`StopRuler`、记忆卡 |
| **7** | **核心功能消失** | 核查全量功能地图全部 40+ 项能力入口仍旧可用，0 功能丢失 |
| **8** | **记忆丢失** | 检查现有四层记忆 (`clio-memory.db`) 升级迁移前后的条目数量、Pinned 状态与导出镜像完全一致 |
| **9** | **数据迁移失败** | 用包含密钥/WebDAV 口令的 0.36 备份包在新安装客户端执行加密恢复，验证聊天、服务、旅伴与记忆完好 |
| **10** | **深色模式无法正常阅读** | 切到深墨灰与纯黑 OLED 模式，核查代码块注释、思考折行、表单分割线与占位字全达到 WCAG AA 清晰可读 |
| **11** | **动画阻塞用户操作** | 侧栏推到 50% 瞬间反向猛拽、正在展开 `PlanCard` 时立即点击发送或切换对话，系统不得出现假死或等待动画播完才响应 |

## 三、双设备帧率与手感独立实测规程

### A. 60Hz 标准刷新率机型测试清单 *(帧预算 `16.67 ms`)* `[待真机实录补全]`
- [ ] iPhone 15 / 16（或开启「限制帧速率」60Hz 测试）连续 5 分钟高密对话滚动，无连续 2 帧 `> 16.67ms` Hitch；
- [ ] `ThinkingBox` 流式每秒 15 次追加期间 CPU 占用稳定，切换底栏附件矩阵不掉帧；
- [ ] 开 6 个外部挂载目录与 200+ 条 `MemoryPageV2` 快速检索无主线程卡顿。

### B. 120Hz ProMotion 机型测试清单 *(严苛帧预算 `8.33 ms`)* `[待真机实录补全]`
- [ ] 聊天列表全速惯性甩动下，验证 `.glassFace` 顶底悬浮栏 + `glassBubble` 对话流的 `FrameMeter` 稳定运行在 120fps（`Hitches` 记录零 Red Hitch）；
- [ ] `DeskSlideHost` 抽屉跟指速率与离手速度继承在 120Hz 下平滑无撕裂；
- [ ] `Core Haptics` 真机实体感受验收：确认普通按钮彻底静默、`StopRuler` 越过推荐基准档（`17pt` / `1.65×` / `100%`）的 `detent` 手感清晰不粘连、朱印三段 `thud()` 干脆有力、开启语音听写期间零震动噪声干扰。
